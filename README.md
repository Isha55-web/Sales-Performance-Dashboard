# Sales-Performance-Dashboard

## Project Overview
This project analyzes sales performance using Microsoft Excel 2019.

## Tools Used
- Microsoft Excel 2019

## Analysis Performed
- Total Sales Analysis
- Total Profit Analysis
- Salesperson-wise Performance
- Region-wise Sales Analysis
- Category-wise Profit Analysis
- Target vs Actual Sales

## Excel Features
- SUMIF
- SUM
- AVERAGE
- COUNTA
- IF
- Pivot Tables
- Charts
- KPI Cards

## Project Files
- Sales_Data.csv – Dataset
- Sales_Performance_Analysis.xlsx – Excel analysis and dashboard
- Dashboard.png – Dashboard screenshot

## Objective
To analyze sales data and create a dashboard that helps understand business performance.
